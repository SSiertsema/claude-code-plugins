Usage in your wireframes

  1. Create a new HTML file with the standard wirekit template (see docs/README.md)
  2. Link css/wireframe.css + optionally css/wireframe-print.css
  3. Copy blocks from /blocks/*.html into your page body
  4. Replace data-placeholder content with your own [bracketed intent]
  5. Add data-region="LABEL" on custom regions to get the badge + wavy border
  6. Add annotations via <aside class="annotation">
